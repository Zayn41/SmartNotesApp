# 📝 Smart Notes Organizer (Java Console App)

A simple and interactive **console-based Notes Manager** built in Java, allowing users to add, view, edit, delete, search, and sort their notes based on priority and creation date.

---

## 🚀 Features

- ✅ Add new notes with title, description, and priority.
- 📋 View all saved notes in a clean format.
- 🔍 Search notes by title keyword.
- 🗑️ Delete notes by exact title.
- ✏️ Edit description and priority of existing notes.
- 📊 Sort notes by:
  - Priority (High > Medium > Low)
  - Created date (Newest First)

---

## 📌 Priority Levels
- `High`
- `Medium`
- `Low`

Used for sorting and identifying task importance.

---

## 🛠️ Technologies Used

- Java 17+
- Java Collections (`ArrayList`, `Iterator`)
- `LocalDateTime` for timestamps
- OOP principles (`Class`, `Encapsulation`, `Method Overriding`)
- Java Console I/O
